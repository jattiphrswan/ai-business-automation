# Roadmap
## Phase 0 — Starter (included)
React dashboard, Node API, demo classifier, local CRM, draft creation, approval queue, audit log.
## Phase 1 — Production foundation
TypeScript backend, PostgreSQL/Prisma, authentication/RBAC, tenant model, tests, CI, Docker, observability.
## Phase 2 — Real AI and knowledge
Provider abstraction, structured classification, prompt templates, policy knowledge retrieval, evaluation dataset, safety checks.
## Phase 3 — Integrations
Gmail/Outlook, WhatsApp, website chat, GoHighLevel/HubSpot CRM, signed webhooks, retry queue and dead-letter handling.
## Phase 4 — Advanced workflow
Editable drafts, approval SLAs, team assignment, escalation, analytics, audit export and configurable automation rules.
## Phase 5 — Scale
Multi-tenancy, usage metering, rate limits, data retention, advanced reporting, disaster recovery and compliance review.
