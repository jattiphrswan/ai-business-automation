# UI/UX Specification
## MVP pages
Dashboard: metric cards, inquiry form, recent inquiries and approval queue tab.
## Production screens
1. Login and organization selector.
2. Dashboard with volume, SLA and approval metrics.
3. Unified inbox with filters, assignment and search.
4. Inquiry detail with source message, CRM timeline, classification, editable draft and activity history.
5. Approval queue with risk badges and reviewer decisions.
6. Contacts and CRM sync status.
7. Integrations settings (email, WhatsApp, CRM, AI provider).
8. Rules/approval policy editor.
9. Audit log and analytics.
## Design system
Clean enterprise SaaS; navy sidebar, indigo actions, neutral background; consistent 8px spacing, accessible contrast, loading/error/empty states and responsive layouts.
## Accessibility
Keyboard access, semantic form labels, visible focus, ARIA status for async updates, WCAG AA target.
